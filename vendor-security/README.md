# Vendor Security

Documents that help your team **check whether an outside company or online tool
is safe to use** — the software, apps, and services that handle your
information.

**What belongs here**
- Questions to ask a vendor before signing up
- Data-privacy and information-handling checklists
- Guidance on reviewing a vendor's promises and track record
- Red flags to watch for

**What does *not* belong here**
- Responding when something goes wrong → see [`incident-response/`](../incident-response/)
- General how-to guides → see [`guides/`](../guides/)
- Reusable fill-in-the-blank forms → see [`templates/`](../templates/)

These are living references. Review and adapt anything before adopting it for
your organization.
