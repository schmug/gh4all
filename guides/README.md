# Guides

**Plain-language how-to documents** that explain a topic or walk through a task,
written for a non-technical reader.

**What belongs here**
- "How to" walkthroughs (e.g., setting up multi-factor authentication)
- Explainers that define terms and concepts
- Best-practice overviews and quick-reference checklists

**What does *not* belong here**
- Blank forms to copy and fill in → see [`templates/`](../templates/)
- Incident response material → see [`incident-response/`](../incident-response/)
- Vendor review material → see [`vendor-security/`](../vendor-security/)

These are living references. Review and adapt anything before adopting it for
your organization.
