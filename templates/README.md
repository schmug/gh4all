# Templates

**Fill-in-the-blank documents** your team can copy and customize. These are
starting points — drop in your organization's name, contacts, and procedures.

**What belongs here**
- Blank policies and plans ready to be personalized
- Forms and worksheets (e.g., asset lists, access reviews)
- "Make your own copy" starter documents

**How to use one**
1. Open the document and read it through.
2. Use the **Fork** button (or the pencil/Edit icon) to make your own copy —
   the main README explains both in plain English.
3. Replace every bracketed `[placeholder]` with your local details.

**What does *not* belong here**
- Finished how-to guides → see [`guides/`](../guides/)
- Incident response material → see [`incident-response/`](../incident-response/)
- Vendor review material → see [`vendor-security/`](../vendor-security/)

These are living references. Review and adapt anything before adopting it for
your organization.
